Voice mode

One WebSocket carries your voice to the provider and the character’s voice back: replies start almost immediately and the model handles turn-taking and interruptions itself. Billed while connected, so the session hangs up when nobody is talking and reconnects on the next sound.

Language model

Placeholders {{date}}, {{hour}} and {{timezone}} are filled in on every request. The exact time is left out on purpose so the prompt stays cacheable; the model can ask for it with a tool.

Realtime voice

The realtime model replaces the language model above and speaks for itself; the system prompt, first message and tools still apply. Changes take effect when you next press Start.

The microphone stays on. xAI resumes the same conversation (kept for about 30 minutes); OpenAI is given the transcript so far. Set 0 to stay connected until you press Stop.

Speech to text

Text to speech
